STEP 1 — Correct folder structure on GitHub
------------------------------------------------

  ├── README.md

------------------------------------------------
STEP 2 — How to upload correctly
------------------------------------------------

Option A (GitHub website):
1. Open your repo: https://github.com/crypto-by-asm/Ai
2. DELETE any wrong nested folders if present
3. Click "Add file" → "Upload files"
4. Drag these items into the ROOT of the repo:
   - index.html
   - .nojekyll
   - css  (the whole folder)
   - js   (the whole folder)
5. Commit changes

Option B (Git):
  git clone https://github.com/crypto-by-asm/Ai.git
  cd Ai
  # delete old files, copy new ones into this folder
  git add .
  git commit -m "Fix CSS and JS paths"
  git push

------------------------------------------------
STEP 3 — GitHub Pages settings
------------------------------------------------

1. Repo → Settings → Pages
2. Source: Deploy from a branch
3. Branch: main  (or master)
4. Folder: / (root)     <--- NOT /docs
5. Save
6. Wait 1–2 minutes, then hard refresh:
   Ctrl + F5  (or Cmd + Shift + R on Mac)
